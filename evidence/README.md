# Kontrolltõendid

- `kanban.jpg`: tegeliku GitHub Projects tahvli vaade. Kokku on 7 backlog'i kaarti ja 1 alustamisvalmis kaart. Töös ja kontrollimisel on nähtav piir 1.
- `arhitektuur.jpg`: arhitektuuriskeem avatud diagrams.net redaktoris.
- `rakendus.jpg`: töötava Django rakenduse ülesannete nimekiri demoandmetega.
- `rakendus-telefon.jpg`: sama nimekiri 360 px telefoni vaates.

Kontrollpildid täiendavad muudetavaid algfaile ja tegelikke töövahendeid. Pilt ei asenda `.drawio` skeemi ega GitHub Projects tahvlit.

Kavandamise tõendites on kontrollitud mõlema algse skeemi XML-i loetavus ning kõik kujundite ja ühenduste ID-viited. Backlog'i JSON-fail sisaldab kaheksat lugu. GitHubi main-harusse on saadetud vähemalt viis sisulist commit'i. Hiljem lisatud Django rakenduse 13 testi läbisid; teostuse kontrollid on kirjeldatud failis `docs/10-rakenduse-teostus.md`.
